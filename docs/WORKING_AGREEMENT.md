# Working Agreement

## Branching
- Use branch names in the format `owner/ID-slug`.

## Pull requests
- Keep pull requests small and focused.
- Require 1 approving review before merge.
- Use squash merge.
- Keep `main` always deployable.

## Weekly checkpoints (Weeks 1-3)
- **Week 1:** `docker compose up` and the mock API work for everyone.
- **Week 2:** A photo from a phone shows as a pin on the map page.
- **Week 3:** An unsafe photo is rejected, a status change reaches the app, and export opens in a spreadsheet.
